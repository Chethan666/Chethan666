# Hollow Lines (working title)

Hollow Lines is a faceless YouTube horror storytelling channel for a global audience, told in a dark hand-drawn stickman style: white chalk-like figures on black ink paper with a single blood-red accent, introduced each episode by a recurring lantern-carrying host called The Storyteller. About three-quarters of the stories are original, set in one shared fictional world, so recurring places, characters and hidden clues reward returning viewers who theorize across episodes. The rest retell folklore from around the world, which brings in search traffic. Each story is built for suspense rather than gore: a hook in the first ten seconds, everyday settings, rising dread, and endings that land as terror, a twist, justice or heartbreak. Every video is clearly presented as fiction or folklore and marked "not made for kids". The channel posts three long episodes a week (8+ minutes) and 60-second horror Shorts on the remaining days, in English. Production is fully automated in two pipelines. The [story factory](STORY_FACTORY.md) is a writers' room of AI models from several companies (today open-weight models on Amazon Bedrock: Kimi, GLM, DeepSeek, Qwen and MiniMax) that pitch, plan, write, edit and audience-test every story, running in GitHub Actions. The production pipeline voices the narration, generates the images and assembles each video locally with the open-source [stickman-video-director](https://github.com/kaomei/stickman-video-director) renderer (see [TOOLS.md](TOOLS.md)).
